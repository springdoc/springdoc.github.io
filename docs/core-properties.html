springdoc-openapi MCP properties

All properties are under the springdoc.ai.mcp prefix. These properties require the springdoc-openapi-starter-webmvc-mcp or springdoc-openapi-starter-webflux-mcp dependency.

Parameter name Default Value Description

springdoc.ai.mcp.enabled

false

Boolean. Enable the MCP tool integration. Since v3.1.1, the MCP surface is opt-in: nothing is registered unless this property is explicitly set to true.

springdoc.ai.mcp.base-url

http://localhost:8080

String. Base URL for tool execution HTTP calls. If not set, defaults to http://localhost:{server.port}.

springdoc.ai.mcp.init-timeout-seconds

30

Integer. Timeout in seconds waiting for the OpenAPI spec at startup.

springdoc.ai.mcp.paths-to-exclude

List of Strings. List of ant patterns for paths to exclude from MCP tool generation.

springdoc.ai.mcp.mcp-endpoint

/mcp

String. The MCP server endpoint path.

springdoc.ai.mcp.dashboard-enabled

false

Boolean. Enable the MCP Developer Dashboard UI.

springdoc.ai.mcp.dashboard-path

/mcp-ui

String. The dashboard UI mount path.

springdoc.ai.mcp.guardrails.require-approval-for-mutating-tools

true

Boolean. When true, calling a mutating tool (POST/PUT/DELETE/PATCH) via MCP returns an approval-required response instead of executing the HTTP call.

springdoc.ai.mcp.guardrails.safe-methods

GET,HEAD,OPTIONS

List of Strings. Comma-separated list of HTTP methods considered safe (read-only). All other methods are treated as mutating.

springdoc.ai.mcp.audit.redact

true

Boolean. When true, values carried by secret-shaped keys (authorization, password, token, api-key, cookie, …) are masked in the audit event before it is logged or stored for the dashboard.
When MCP is enabled, springdoc.pre-loading-enabled is automatically forced to true by an environment post-processor, ensuring the OpenAPI specification is available at startup for tool registration.
The MCP endpoints (/mcp, /mcp-ui and /api/mcp-admin/**) are integration surfaces, exactly like /swagger-ui: they provide no authentication or authorization of their own and must be secured by your application. In particular, springdoc.ai.mcp.guardrails.require-approval-for-mutating-tools is a human-in-the-loop confirmation step, not an access-control boundary.
